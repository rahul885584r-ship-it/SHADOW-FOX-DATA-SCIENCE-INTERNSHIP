## 📈 Visualization Types

| Visualization   | Purpose                                            |
| --------------- | -------------------------------------------------- |
| Line Chart      | Shows changes across an ordered sequence           |
| Bar Graph       | Compares values between categories                 |
| Histogram       | Shows frequency distribution                       |
| Scatter Plot    | Shows relationship between two numerical variables |
| Pie Chart       | Shows parts of a whole                             |
| Area Chart      | Highlights magnitude and changes                   |
| Box Plot        | Summarizes numerical data and identifies outliers  |
| Heatmap         | Helps inspect correlations                         |
| Regression Plot | Shows relationship with a fitted regression line   |

## 🔥 Matplotlib vs Seaborn

**Matplotlib** provides detailed control over individual plot elements and is useful when precise customization is required.

**Seaborn** provides a higher-level interface for statistical and exploratory visualization and works smoothly with Pandas DataFrames.

Both libraries can be used together for effective data analysis and visualization.

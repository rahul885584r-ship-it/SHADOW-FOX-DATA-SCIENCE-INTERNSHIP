# 🟡 02. Intermediate Project — Delhi Air Quality Analysis

### 📌 Delhi Air Quality Data Analysis

This project analyzes **Delhi air-quality observations** using Python, Pandas, NumPy, Matplotlib, and Seaborn.

The main focus is on **PM2.5, PM10, and other air-quality parameters**.

### 🔧 Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

### 📂 Dataset

The dataset contains air-quality measurements including:

* CO
* NO
* NO2
* O3
* SO2
* PM2.5
* PM10
* NH3
* Date

The working dataset contains **561 observations and 9 columns**.

### 🔄 Analysis Workflow

* Load CSV dataset
* Inspect dataset structure
* Check rows and columns
* Analyze data types
* Generate descriptive statistics
* Check missing values
* Handle duplicate/null records
* Convert date into datetime format
* Create monthly data
* Perform PM2.5 analysis
* Analyze relationships between air-quality parameters

### 📈 Visualizations

* PM2.5 Trend Over Time
* Average PM2.5 by Month
* PM2.5 Distribution
* PM2.5 Box Plot
* Monthly PM2.5 Trend
* Correlation Heatmap
* PM2.5 vs PM10 Scatter Plot

### 🎯 Objective

To perform a complete **beginner-to-intermediate data-analysis workflow** on real-world air-quality data.

# 🔴 03. Advanced Project — IPL Fielding Performance Analysis

### 📌 IPL Fielding Performance Analysis

This advanced project analyzes **IPL fielding performance** using Python.

The analysis focuses on **Performance Score (PS), fielding actions, player-wise comparison, ranking, and top performers**.

### 🔧 Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

### 🔄 Analysis Workflow

* Import Python libraries
* Load the dataset
* Inspect dataset structure
* Analyze columns and data information
* Perform descriptive analysis
* Calculate Performance Score
* Identify the best player
* Compare player performance
* Analyze fielding actions
* Rank top performers
* Create visualizations

### 🏆 Performance Score

A weighted **Performance Score (PS)** is calculated according to the project's defined formula.

The score is then used to compare players and identify the highest-performing fielders.

### 📊 Analysis Includes

* Player-wise Performance Score
* Best Player Identification
* Fielding Performance Comparison
* Fielding Action Analysis
* Top Performer Ranking
* Performance Visualizations

The project ranks players based on Performance Score to identify top performers.

### 🎯 Objective

To demonstrate how Python can be used for **sports analytics**, player comparison, performance measurement, and data-driven decision making.

# 🏏 IPL Fielding Performance Analysis

This project analyzes **IPL fielding performance** using Python. The analysis focuses on fielding actions, Performance Score (PS), player-wise comparison, ranking, and data visualization.

## 📌 Project Overview

The objective of this project is to analyze and compare IPL players based on their fielding performance.

The project includes:

* Dataset loading
* Data inspection
* Data-quality checks
* Descriptive analysis
* Performance Score calculation
* Best-player identification
* Player ranking
* Fielding-performance analysis
* Data visualization

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🔄 Project Workflow

1. Import required Python libraries
2. Load the IPL fielding dataset
3. Inspect the dataset
4. Check rows and columns
5. Examine data information
6. Perform descriptive analysis
7. Calculate Performance Score
8. Identify the best-performing player
9. Create performance visualizations
10. Analyze fielding actions
11. Rank top-performing players

## 📊 Performance Score

The project calculates a **Performance Score (PS)** using the weighted formula defined in the project.

This score is then used to compare players and identify the highest-performing fielders.

## 🏆 Best Player

The project identifies the player with the **highest Performance Score** and compares player performance using the calculated score.

## 📈 Data Visualizations

Different visualizations are used to make player performance easier to understand and compare.

The project includes analysis of:

* Performance Score
* Player-wise performance
* Fielding actions
* Top performers
* Player rankings
* Fielding-performance comparisons

## 🏅 Top Performers

Players are ranked or selected based on their **Performance Score** to identify the top-performing fielders in the dataset.
